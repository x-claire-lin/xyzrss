如何添加新的播客

  1. 在上面的输入框粘贴小宇宙 RSS 地址。
  2. 复制生成的配置行。
  3. 打开 GitHub 上的 feeds.txt。
  4. 把配置行加入文件并提交。
  5. GitHub Actions 会自动生成新的 RSS。

本项目完全使用 GitHub Pages + GitHub Actions， 不需要 Cloudflare Worker 或其他服务器。
